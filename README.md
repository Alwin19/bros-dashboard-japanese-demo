# 地元病院の経営ダッシュボード開発（進行中）

---

### 概要
地元病院の業務効率化を目的として、毎日手動で行われている経営データ集計作業を経営ダッシュボードとして自動化することを提案・開発中のプロジェクトです。病院運営に関する主要な指標を可視化し、意思決定を支援することを目的としています。

### デモ（以下のリンクからアクセス）
🔗 **[https://bros-dashboard-japanese-demo.vercel.app/](https://bros-dashboard-japanese-demo.vercel.app/)**

### 役割分担
- **フロントエンド開発**：私
- **バックエンド開発**：当病院ITチーム
